# Видео на Amazon: четыре площадки / Amazon video by placement

Один и тот же ролик нельзя переставлять между площадками. У каждой свои контейнеры, длительность, вес и пропорции — сводка ниже снята с живых страниц Amazon **16.11.2026**.

The same file cannot be reused across placements: each has its own container, duration, weight and aspect. Matrix below fetched live on **2026-11-16**.

---

## 0. Сводка / At a glance

| Площадка | Файл | Макс. вес | Разрешение | Длительность | Пропорции |
|---|---|---:|---|---|---|
| Листинг (shoppable video) | MOV / MP4 | 5 ГБ | до 1080p | 1–12 мин | 16:9 или 9:16 |
| A+ Premium — full video | только MP4 | 200 МБ | 960×540 мин | 180 с макс | плеер модуля |
| A+ Premium — video with text | только MP4 | 200 МБ | 800×600 мин | 180 с макс | блок 4:3 |
| Store — video tile | MP4 / H.264 | не опубликован `[verify]` | 1280×640 / 640×640 / 450×320 | не опубликована | 6:4–8:3 или 3:4–4:3 |
| Store — background video | MP4 / H.264 | не опубликован `[verify]` | 1280×640 мин | 2–20 с | 6:4–8:3 (large 3:4–8:3) |
| Sponsored Brands video (PPC) | MP4 / MOV | 500 МБ | 1280×720 / 1920×1080 / 3840×2160 | 6–45 с (≤20 рек.) | только 16:9 |

## 1. Видео в карусели листинга / PDP listing video

Загрузка: Seller Central → Upload and manage your product videos.

| Параметр | Значение |
|---|---|
| Формат | **MOV или MP4** |
| Максимальный вес | **5 ГБ** |
| Разрешение | до **1080p** |
| Пропорции | **16:9 гориз.** или **9:16 верт.** |
| Длительность | **1–12 минут** |
| Обложка/превью | JPEG, PNG, GIF, BMP, **до 5 МБ** |
| Условия | аккаунт активен >3 мес.; ASIN создан; видео привязано минимум к одному ASIN |
| Синхронизация | US–Canada общие листинги синхронизируются; других маркетплейсов нет |

Качество (требование Amazon): товар хорошо виден, чистый звук, нормальный свет, профессиональная подача, достоверная информация о товаре. Плюс Community Guidelines.

**AI-дисклоуз (обязательно).** Если в видео есть **фотореалистичные люди, сгенерированные ИИ**, файл нужно пометить ключевым словом `contains-synthetic-performer` в поле `dc:subject` (XMP) через IPTC-совместимый редактор. Тег не нужен для реальных людей (даже обработанных ИИ), для персонажей кино/игр, для видео без людей и для нереалистичных персонажей.

`[forum-lifehack]` 1–12 минут — это не «тизер», а продукт-фильм: первые 5 секунд решают, досмотрят ли. Главный товар — в первом кадре, логотип — в конце.

## 2. A+ Basic

Видео-модуля нет. В таблице Amazon «Video & Hotspot» заполнено только для Premium. Не обещать видеоблок на Basic-раскладке.

## 3. A+ Premium

### 3.1. Premium full video

| Параметр | Значение |
|---|---|
| Формат | **только .mp4** (Flash не поддерживается) |
| Минимальное разрешение | **960×540** |
| Максимальный вес | **200 МБ** |
| Максимальная длина | **180 с** |
| Превью (состояние покоя) | **1464×600** мин, png/jpg/jpeg |
| Заголовок | 80 знаков |
| Текст | 300 знаков |
| Мобильный | desktop-ассеты, отдельного мобильного видео нет |

### 3.2. Premium video with text

| Параметр | Значение |
|---|---|
| Видео-блок | **800×600** мин |
| Максимальный вес | **200 МБ** |
| Максимальная длина | **180 с** |
| Превью | **800×600** мин |
| Заголовок / подзаголовок | 80 / 40 знаков |
| Текст | 500 знаков |
| Название видео / описание | 50 / 200 знаков |

Правила:

- В гайде Amazon идеальная длина — около **10 секунд**; большая часть зрителей останавливается после этого. 180 с — потолок, не цель.
- В Premium можно несколько видео-модулей (до 7 модулей на странице, 19 шаблонов).
- AI-дисклоуз про фотореалистичных людей действует и здесь.
- Видео для A+ загружается в A+ Content Manager, а не в библиотеку видео листинга: другой файл, другие лимиты.

---

## 4. Brand Story

Один модуль, до 19 карточек в карусели: полноэкранные фоны, карточки «картинка + текст», ссылки на товары и Brand Store. **Видео-модуль не документирован** — не планировать без проверки в живом билдере `[verify]`.

---

## 5. Brand Store

### 5.1. Video tile (по клику)

| Плитка | Мин. обложка | Мин. видео | Пропорции | Файл |
|---|---|---|---|---|
| Full width | 3000×1500 | 1280×640 | 6:4–8:3 | MP4, H.264 |
| Large | 1500×1500 | 640×640 | 3:4–4:3 | MP4, H.264 |
| Medium | 1500×750 | 450×320 | 6:4–8:3 | MP4, H.264 |

Нужны **и видео, и обложка**: обложка — состояние покоя до нажатия play. У плеера есть play/pause, звук и полный экран.

### 5.2. Background video (автоплей, без звука)

| Плитка | Мин. видео | Макс. высота | Длительность | Пропорции |
|---|---|---|---|---|
| Full width | 1280×640 | 1500 px | 2–20 с | 6:4–8:3 |
| Large | 1280×640 | 640 px | 2–20 с | 3:4–8:3 |
| Medium | 1280×640 | 320 px | 2–20 с | 6:4–8:3 |

Обложка не нужна. Автоповтор без звука, играет внутри страницы на ПК и телефоне, без элементов управления.

### 5.3. Лимиты страницы

- До **20 секций** на страницу, из них максимум **4 background video**.
- У каждой страницы встроенная шапка + минимум 1 контентная плитка.
- Максимальный вес видеофайла для Store на странице спецификаций не опубликован → `[verify]` в Store Builder. Лимит 5 МБ относится к изображениям.

## 6. Sponsored Brands video (PPC)

| Параметр | Спецификация |
|---|---|
| Длительность | 6–45 с (≤20 с настоятельно рекомендуется) |
| Размеры | 1280×720, 1920×1080 или 3840×2160 |
| Вес | ≤500 МБ |
| Формат | .MP4 или .MOV |
| Пропорции | **только 16:9**, square pixel |
| Кодек | H.264 или H.265 |
| Профиль | Main или Baseline |
| Частота кадров | 23.976 / 23.98 / 24 / 25 / 29.97 / 29.98 / 30 fps |
| Битрейт видео | ≥1 Mbps (4+ рекомендуется) |
| Развёртка | Progressive |
| Аудио | PCM, AAC или MP3; stereo/mono; ≥96 kbps; ≥44.1 kHz |

Креативные ограничения:

- Стартует без звука; кнопка mute — в правом нижнем углу. **Текст и важное — не в правом нижнем углу.**
- Нельзя letterboxing / pillarboxing: без чёрных, цветных и размытых полос.
- Язык на экране = язык маркетплейса.
- Название бренда и логотип — на end card, не в первую секунду.
- Действует Amazon Ads creative acceptance policy, реклама проходит ревью.

## 7. Матрица производства: одна съёмка — четыре файла

| Файл | Длина | Звук | Текст на экране | Экспорт |
|---|---|---|---|---|
| Листинг | 60–180 с, главами | да, чистый | скупо, крупно | MOV/MP4, 1080p, 16:9 (или 9:16) |
| A+ Premium full | 10–20 с | опционально | заголовок + 1 строка | MP4, 1280×720+, ≤200 МБ, превью 1464×600 |
| Store video tile | 15–30 с | опционально | нет | MP4 H.264, по пропорциям плитки |
| Store background | 2–20 с, бесшовный луп | нет | нет | MP4 H.264, 1280×640+, высота по плитке |
| SBV | 15–20 с | да + музыка | end card CTA | MP4, 1920×1080, 16:9, ≤500 МБ |

Сдавать мастер в максимальном разрешении + по одному экспорту на площадку. Держать «чистую» версию без запечённого текста — для переиспользования на других языках.

## 8. Чек-лист / QA checklist

- [ ] Файл соответствует площадке: контейнер, кодек, длительность, пропорции.
- [ ] Листинг: MOV/MP4, ≤5 ГБ, ≤1080p, 1–12 мин, 16:9 или 9:16, обложка <5 МБ.
- [ ] A+ Premium: только MP4, ≤200 МБ, ≤180 с, есть превью 1464×600 (или 800×600).
- [ ] Store: у video tile есть обложка; background video 2–20 с, без звука и без обложки.
- [ ] SBV: только 16:9, без полос, правый нижний угол свободен, end card с брендом, язык = маркетплейс.
- [ ] Ни цен, ни скидок, ни отзывов, ни превосходных степеней, ни чужих логотипов, ни цифр прочности без протокола — ни в одном кадре.
- [ ] Фотореалистичные люди от ИИ помечены `contains-synthetic-performer` в XMP.
- [ ] Товар на экране = товар в карточке (модель, цвет, комплект).
- [ ] Мобильная проверка: первый кадр понятен без звука, текст выше элементов плеера.
